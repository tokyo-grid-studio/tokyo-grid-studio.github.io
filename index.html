Tokyo Grid Studio

最終更新日: 2026年9月

Tokyo Grid Studio(以下「当方」)は、個人が運営するデジタルアート販売事業です。本ポリシーは、Pinterest API連携アプリケーション「Tokyo Grid Studio Automation」における情報の取り扱いについて説明するものです。

1. 収集する情報

本アプリは、当方自身が保有するPinterestアカウントおよびEtsyショップの運営のみを目的としています。第三者(顧客・訪問者等)の個人情報を収集、保存、共有することはありません。

2. 利用目的

本アプリは、当方自身が制作したデジタルアート作品を、当方自身のPinterestボードに投稿する作業を自動化するためにのみ利用されます。

3. 第三者への提供

本アプリが取得する情報を、第三者に販売、貸与、共有することはありません。

4. データの保管

認証情報(アクセストークン等)は、当方が管理するローカル環境にのみ保存され、外部のサーバーには送信されません。

5. お問い合わせ

本ポリシーに関するお問い合わせは、当方のEtsyショップページを通じてご連絡ください。
